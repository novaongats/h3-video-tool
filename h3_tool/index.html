文章や画像から、音声つき動画をワンクリック生成（MiniMax H3 / RunPod）
はじめに1回だけ：RunPodのAPIキーを設定します
1. RunPodの設定ページを開く
2. 「API keys」の欄で Create API key を押す（名前は何でもOK・権限は All / Read & Write）
3. 表示された長い文字列をコピーして、下に貼り付けて保存
