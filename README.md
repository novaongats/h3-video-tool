# H3かんたん動画メーカー

MiniMax H3（動画生成AI）を、ComfyUIを触らずに簡単に使うためのローカルツール。

- 起動: `H3かんたん動画メーカー.bat` をダブルクリック（要 Python 3.10+）
- 使い方は `説明書.html`、コツは画面内の「💡コツ・FAQ」を参照
- ツールは起動時にこのリポジトリから自動アップデートされます

## 2つの動作モード

`h3_tool/config.json` で切り替えます（このファイルは各PCで作成／リポジトリには含まれません）。

### ① クラウドモード（既定）— RunPodのGPUをレンタルして生成
画面の設定ページでRunPodのAPIキーを登録します。3人まで同じサーバーを共有できます。

### ② ローカルモード — このPCのComfyUIで生成（レンタル料0円）
`config.json` に以下を記述します。**APIキーは不要で、クラウドには一切接続しません。**

```json
{
  "local_mode": true,
  "local_url": "http://localhost:8188",
  "auto_stop": false
}
```

事前にこのPCへComfyUIとMiniMax H3のモデルを導入しておく必要があります。
導入手順は `事務所PC導入指示プロンプト.md` を参照してください。
